# Many inhibitors with defined yeast targets have limited activity against the microsporidian *Nematocida parisii*

Code and data to reproduce the figures and statistical analyses in:

> Huang Q, Pan G, Chen J, Reinke AW. Many inhibitors with defined yeast targets have limited activity against the microsporidian *Nematocida parisii*. *Parasitology International* **117**, 103389 (2027). https://doi.org/10.1016/j.parint.2026.103389

[Reinke Lab](https://github.com/reinkelab-utoronto), University of Toronto

## Overview

We tested small-molecule inhibitors with known *Saccharomyces cerevisiae* targets for activity against the microsporidian *N. parisii* infecting *Caenorhabditis elegans*. For each compound we identified whether the yeast target has an *N. parisii* ortholog and calculated its amino-acid identity.

This repository contains:

- the R scripts that generate Fig. 1, Fig. 2 and Supplementary Fig. S1
- the Dunnett's test results reported in Table S1
- the underlying data

The scripts are the exact code used for the published article. Only the file names have changed.

## Data

Each infection and gravidity file has one row per treatment. Its columns are concentration × biological replicate (`10 µM rep1` … `100 µM rep3`), and the values are percentages of animals. Each per-figure input file contains the same values as the matching sheet of `Data_S1.xlsx`.

| File | Measurement | Controls |
|---|---|---|
| `all infection.xlsx` | % animals infected (10, 40, 100 µM) | `Uninfected+DMSO`, `Infected+DMSO` |
| `severe infection.xlsx` | % animals with severe infection (100 µM) | `Uninfected+DMSO`, `Infected+DMSO` |
| `gravidity infected.xlsx` | % gravid animals after *N. parisii* exposure (10, 40, 100 µM) | `Uninfected+DMSO`, `Infected+DMSO` |
| `gravidity uninfected.xlsx` | % gravid uninfected animals (10, 40, 100 µM) | `DMSO` |

`conservation data.xlsx` has one row per compound, with these columns:

- `drug`
- `Target`: the yeast target gene(s)
- the yeast UniProt accession
- `N. parisii name`: the ortholog locus ID
- `N. parisii identity`: % amino-acid identity, or `N/A` when there is no detectable ortholog
- the reference for the target assignment

## Scripts and outputs

| Script | Figure | Statistics | Inputs | Outputs |
|---|---|---|---|---|
| `fig1_infection.R` | **Fig. 1**: (A) % infected at 10/40/100 µM, with yeast target, *N. parisii* ortholog and % identity strips; (B) % severe infection at 100 µM | One-way ANOVA per concentration, then Dunnett's test vs `Infected+DMSO` | `all infection.xlsx`, `severe infection.xlsx`, `conservation data.xlsx` | `figure_panelAB.pdf/.png`, `panelA_stats_dunnett.csv` (Table S1, Figure 1A), `panelB_stats_dunnett.csv` (Table S1, Figure 1B) |
| `fig2_gravidity.R` | **Fig. 2**: (A) % gravid infected animals; (B) % gravid uninfected animals | One-way ANOVA per concentration, then Dunnett's test vs `Infected+DMSO` (A) or `DMSO` (B) | `gravidity infected.xlsx`, `gravidity uninfected.xlsx` | `figure_gravidity.pdf/.png`, `gravidity_panelA_stats.csv` (Table S1, Figure 2A), `gravidity_panelB_stats.csv` (Table S1, Figure 2B) |
| `figS1_target_conservation.R` | **Fig. S1**: (A) ortholog identity vs % inhibition of infection at 100 µM; (B) % inhibition by ortholog status | Pearson and Spearman correlation; Wilcoxon rank-sum tests vs "No ortholog" | `Data_S1.xlsx`, `conservation data.xlsx` | `figure_conservation_two_panel.pdf/.png`, `conservation_figure_data.csv`, `panelA_correlation_stats.csv`, `panelB_group_summary.csv`, `panelB_stats.csv` |

In Fig. S1, % inhibition = 100 × (mean infected<sub>Infected+DMSO</sub> − mean infected<sub>compound</sub>) / mean infected<sub>Infected+DMSO</sub>, using the 100 µM infection data. The third group in panel B removes compounds previously reported to inhibit microsporidia (fumagillin, dexrazoxane and albendazole).

The Kruskal-Wallis/Dunn and normality tests in Table S1 are not generated by the scripts in this repository.

## Requirements

- R ≥ 4.3. The published analysis used R 4.5.2 and RStudio 2026.1.1.403.
- CRAN packages: `readxl`, `tidyverse`, `ggplot2` (≥ 4.0), `patchwork` (≥ 1.3), `ggnewscale`, `ggrepel`, `multcomp`

Install them from the repository root with:

```r
source("scripts/00_install_packages.R")
```

## Reproducing the analysis

The scripts read their input files from the **working directory** and write their outputs there too. To run them, set the working directory to `data/` and run each script.

From a terminal:

```bash
git clone https://github.com/reinkelab-utoronto/Npar-yeast-target-inhibitors.git
cd Npar-yeast-target-inhibitors/data
Rscript ../scripts/fig1_infection.R
Rscript ../scripts/fig2_gravidity.R
Rscript ../scripts/figS1_target_conservation.R
```

In RStudio, open `Npar-yeast-target-inhibitors.Rproj` and run:

```r
setwd("data")
source("../scripts/fig1_infection.R")
source("../scripts/fig2_gravidity.R")
source("../scripts/figS1_target_conservation.R")
```

The figures and CSV files appear in `data/`. Copies generated this way are already in `figures/` and `results/`.

### Notes on reproducibility

- **Dunnett p-values vary slightly between runs.** They come from randomized numerical integration (`mvtnorm`), so values in the 4th decimal place can change from run to run. In our test runs, every p-value was within 0.0012 of Table S1, and every significance call matched. Comparisons with p close to a cutoff (e.g. cycloheximide in Fig. 1B, p ≈ 0.0001) can occasionally gain or lose one star. To get the same numbers every time, run `set.seed(1)` before sourcing a script.
- **Compound order depends on the system locale.** Compounds are sorted with `sort()`, which follows the system locale. The published figures were made in an English locale (Albendazole before AN-2690). This is the default on macOS and Windows. On Linux in the `C` locale, set an English UTF-8 locale first, e.g. `LC_ALL=en_US.UTF-8 Rscript ../scripts/fig1_infection.R`.
